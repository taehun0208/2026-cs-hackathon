# 디자인 결정

컴퓨터학부 학생이 직무를 고르고 작은 업무를 직접 바꿔보는 작업실입니다. 2026-11-23 개편에서는 소개와 장식보다 업무 선택·실행·기록을 먼저 읽게 정리했습니다. 현재 변경은 디자인 검토 브랜치이며 운영 반영은 별도입니다.

## 방향

- 홈은 제목·한 문장 소개·여섯 업무 선택으로 구성합니다. 정적 AI 추천, 큰 파스텔 미니 화면, 반복 개념 목록을 제거했습니다. 최근 미완료 작업의 이어하기를 먼저 보여주고 완료한 작업은 다시 열기로 구분합니다.
- 흰 표면·중립 배경·진한 글자를 사용합니다. 파랑은 행동·선택·링크에 집중하며 장식용 그라데이션과 반복 그림자는 사용하지 않습니다. 실제 실행 결과·게임 시뮬레이션의 의미 있는 색 구분은 유지합니다.
- Pretendard 가변 글꼴과 OFL 라이선스를 프로젝트에 담았습니다. 외부 글꼴 서버를 호출하지 않습니다. 본문은 한국어 단어 단위의 줄바꿈을 우선합니다.
- 페이지 제목은 데스크톱 38~44px·모바일 30~31px, 업무 제목 21~22px, 본문 15~17px를 중심으로 위계를 둡니다. 동의·실행 근거·저장 안내를 작은 장식 문구로 숨기지 않습니다.
- 홈·게임은 3/2/1열 탐색을 사용합니다. 모바일 헤더는 로고·도움말과 주 메뉴를 두 행으로 나눠 도움말을 계속 찾을 수 있게 합니다. 저장 상태도 별도로 유지합니다.
- 실습은 조건·코드/결과·코치의 세 영역을 보존하고 실행 버튼을 주 행동으로 둡니다. AI 질문은 펼침 화살표와 명확한 문구를 사용합니다. 실제 도구 활동·검수 근거만 표시하는 정책은 그대로입니다.
- 회고에서 아직 필요한 입력을 안내합니다. 제출과 서버 저장을 구분하고 기존 저장 상태·재시도·초안 복구·기한 안내를 유지합니다. 비교표에는 직무 수별 최소 너비와 키보드로 접근 가능한 가로 스크롤 영역을 둡니다.
- 기록·비교·도움말·파일럿은 직접적인 제목과 본문으로 정리했습니다. 분석 동의는 확인 중/변경 중/오류/켜짐/꺼짐을 구분하고 안내받은 번호를 먼저 고르게 합니다. 수집·철회·삭제 정책은 바꾸지 않습니다.

| 용도           | 값        |
| -------------- | --------- |
| 기본 표면      | `#FFFFFF` |
| 구역 배경      | `#F9FAFB` |
| 주요 글자      | `#191F28` |
| 본문 보조 글자 | `#4E5968` |
| 작은 보조 글자 | `#657181` |
| 구분선         | `#E5E8EB` |
| 주요 행동      | `#2563EB` |

초점 표시와 줄어든 모션 설정을 유지합니다. 주요 색 대비 검사는 전체 접근성 인증을 의미하지 않습니다.

## 참고와 적용

- [Toss Product Principles](https://toss.im/tossfeed/article/tossproductprinciples): 쉬운 말과 분명한 행동. 직무 선택→직접 해보기에 집중하고 반복 소개를 줄이는 데 참고했습니다.
- [Toss Design System Typography](https://tossmini-docs.toss.im/tds-mobile/foundation/typography/): 글자 위계·행간·보조 정보 구분을 작업 화면에 맞췄습니다.
- [토스 공식 사이트](https://toss.im): 실제 화면을 캡처해 간결한 헤더와 여백을 검토했습니다. 사진·영상·로고를 서비스 자산으로 가져오지 않았습니다.
- [Frontend Mentor 과제 목록](https://www.frontendmentor.io/challenges): 해야 할 작업 중심의 탐색 구조를 참고했습니다.
- [Codecademy 카탈로그](https://www.codecademy.com/catalog): 분야별 탐색과 짧은 학습 단위의 정보 구분을 참고했습니다.
- [Pretendard 공식 배포](https://github.com/orioncactus/pretendard): 한국어 글꼴과 라이선스 출처입니다.

디자인 방향·게임 구현·UX/접근성 검토를 세 에이전트에게 나눠 진행한 뒤 실제 화면을 재검토했습니다. 학생 사용성 실험 결과는 아닙니다. [화면별 근거와 검증](DESIGN-QA.md)을 참고하세요.
