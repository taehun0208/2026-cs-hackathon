# 해보기

**컴퓨터학부 학생이 작은 업무를 직접 해보며 다음에 배울 일을 고르는 개발 직무 체험 서비스**

서비스: https://haebogi-career-lab.vercel.app

## 확인하려는 문제

직무 설명을 읽는 것만으로 업무의 차이를 이해할 수 있는지, 큰 프로젝트의 환경 설정이 첫 경험을 가로막는지, 체험이 다음 학습 선택에 도움이 되는지를 확인합니다. 현재는 기획 가설이며 실제 학생 조사 결과로 표현하지 않습니다.

## 학생이 하는 일

프론트엔드·백엔드·데이터 분석·AI 엔지니어·보안·클라우드/SRE 중 작은 업무를 고릅니다. 같은 교내 행사 맥락과 JavaScript로 준비된 코드의 한 줄을 수정하고 실행합니다. 다섯 확인 상황과 실제 실행 스냅샷을 보고, 흥미·난이도·다시 해볼 의향·메모·다음 활동과 이유를 남깁니다. 두 직무의 회고를 나란히 비교합니다.

## 차별을 보여주는 장면

백엔드에서 신청 인원과 정원이 같아도 마감하도록 `>`를 `>=`로 바꾸고 실행합니다. 같은 형식으로 남긴 프론트엔드 회고와 비교한 뒤, 직접 고른 다음 활동과 이유를 확인합니다. 직무 전체를 재현하거나 적성을 판정하는 범위는 아닙니다.

## AI와 실행의 경계

AI 코치는 동의한 현재 코드·질문·참고 실행 보고를 사용합니다. 공식 과제와 확인 항목을 제한된 도구 루프로 읽고 질문 의도를 분류합니다. 서버가 검수된 힌트와 근거를 연결하며 자유 설명을 그대로 표시하지 않습니다. 사용자의 코드는 브라우저의 분리된 환경에서 실행하고 서버 AI가 대신 실행하지 않습니다. 연결·응답·한도 문제에는 기본 힌트로 이어갑니다.

## 구현과 검증 근거

Next.js·Vercel·Neon을 사용합니다. 기술 확인은 자동 회귀, API 저장·분리·삭제, 실제 수정·실행·회고·비교와 게임 흐름으로 나눕니다. 화면의 QA 점수와 문장은 합성 입력이며 사용자 만족도 증거가 아닙니다. 저장 동시성·게임 기록·후속 활동과 AI 추정 예약예산을 통합한 코드에서 단위 테스트 199개를 통과했습니다. 실제 Neon 예산 마이그레이션·동시 예약·CAS·정산·정리 검증을 마쳤습니다. 일 $1·월 $10은 앱의 추정 예약예산이며 공급자 청구 상한 보장이 아닙니다. 최대 예약액 $0.162144 때문에 잔액이 남아도 기본 힌트로 전환할 수 있습니다. 최신 통합판 빌드·타입 검사도 통과했습니다. 이 범위는 PR #44로 main에 반영하고 운영 배포·실제 AI·정산을 확인했습니다. 이번 보안 후속 작업은 [보안 검토](../SECURITY-REVIEW.md)를 함께 확인합니다. 비용 정책의 범위는 [AI-BUDGET.md](../AI-BUDGET.md)를 따릅니다.

## 학생 검증과 협업

3명 예비테스트에서 첫 수정의 막힘, 회고 완료, 같은 사전·사후 명확성 질문, 다음 행동과 이유를 관찰할 준비를 합니다. 실제 응답은 아직 없습니다. 이후 정식 12명 파일럿과 동의자 대상 7일 확인으로 이어갑니다. 기획·프론트·백엔드·디자인·발표·사용자 검증 담당은 모두 미정(제안안)입니다. 실제 배정 후 근거를 채웁니다.

심사 근거: 기술 완성도 30, 창의성 25, 실용성 25, 발표·협업 20. [배점별 증거](JUDGING.md)와 [시연 대본](DEMO-SCRIPT.md)을 함께 사용합니다.
