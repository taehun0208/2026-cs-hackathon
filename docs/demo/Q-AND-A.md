# 예상 질문과 답변

## 단순 코딩 문제 사이트와 무엇이 다른가요?

작은 업무를 해본 뒤 흥미·어려움·다음 행동을 같은 형식으로 기록하고 직무끼리 비교하는 흐름에 집중했습니다. 실제 업무 전체나 일반 코딩 교육과의 우월성을 입증한 것은 아닙니다. 학생 관찰로 이 연결이 다음 학습 선택에 도움이 되는지 확인할 계획입니다.

## 모든 직무를 JavaScript로 체험하는 이유는 무엇인가요?

환경과 문법 차이를 줄이고 작은 업무의 논리에 집중하려는 초기 선택입니다. 언어가 실제 직무의 전체 기술 스택을 대표한다고 말하지 않습니다.

## 처음 배우는 학생도 할 수 있나요?

새 체험은 준비된 코드의 한 줄부터 수정하며 문법 예제·힌트·참고 풀이가 있습니다. JavaScript 기초는 도움이 됩니다. 누구나 쉽게 마친다고 보장하지 않고 3명 예비테스트에서 첫 수정의 막힘과 진행자 개입을 기록하려고 합니다.

## AI가 틀린 설명을 하면 어떻게 하나요?

모델의 자유 설명 대신 질문 의도를 분류하고 서버가 검수된 힌트·근거·다음 행동을 연결합니다. 형식·근거가 맞지 않으면 기본 힌트로 전환합니다. 질문 의도 분류가 모든 표현에서 정확하다는 보장은 없어 별도 합성 문항 평가와 회귀 검증을 합니다.

## AI 품질 수치는 있나요?

`docs/AI-QUALITY.md`의 2026-11-22 평가 기록에서 기존 36개를 두 번 평가한 72/72, 추가 질문 32/32가 고정 기대 힌트를 선택했습니다. 합성 사례·당시 코드와 모델의 결과이며 모든 질문의 정확도나 학생 만족도 수치가 아닙니다. 최종 통합 코드를 새로 실호출 평가했다고 말하지 않습니다.

## Agentic한 부분은 어디인가요?

코치가 과제와 확인 항목을 도구로 읽고 질문 의도를 반환하는 제한된 도구 루프입니다. 도구 종류·호출 횟수와 출력 범위를 제한하고 서버가 근거를 검사합니다. 완전 자율 개발자나 자유로운 다중 에이전트 시스템이라고 설명하지 않습니다.

## AI가 학생 코드를 실행하나요?

실행은 브라우저의 분리된 iframe·Worker에서 수행합니다. 서버 AI는 공식 확인 항목과 브라우저가 보낸 미검증 보고를 참고하며 사용자 코드를 서버에서 실행하지 않습니다.

## 테스트를 전부 통과해야 완료인가요?

직접 수정한 코드를 실행하고 회고를 남겼는지를 봅니다. 일부 실패·실행 오류가 있어도 회고할 수 있습니다. 참고 풀이만 실행한 경우와 직접 수정한 경우를 구분합니다.

## 점수로 적성을 추천하나요?

흥미·체감 난이도·다시 해볼 의향은 자기 응답입니다. 검수 규칙으로 다음 학습 후보와 이유를 제시하고 사용자가 직접 고릅니다. 직무 적성·실력·취업 가능성을 판정하지 않습니다.

## 저장과 개인정보는 어떻게 다루나요?

익명 브라우저 쿠키로 기록을 구분하고 서버 저장 시각·보관 기한·초안 복구·삭제를 안내합니다. AI 전송 동의와 분석 참여는 별도입니다. 분석에는 코드·질문·회고 원문을 복제하지 않습니다. 최종 통합의 동시 저장과 게임 기록 정책은 실제 배포 버전의 안내를 기준으로 설명합니다.

## AI 비용은 어떻게 막나요?

횟수 제한에 더해 일 $1·월 $10의 앱 추정 예약예산을 구현했습니다. 호출 전 비용을 예약하고 사용량으로 정산하며 실제 Neon에서 동시 예약·CAS·정산·정리를 검증했습니다. 최대 예약액은 $0.162144이므로 잔액이 남아도 예약액이 부족하면 기본 힌트로 전환할 수 있습니다. 앱에서 추정하고 통제하는 범위이며 공급자 청구 상한이나 원가 최소를 보장하지 않습니다. 운영 반영은 대기입니다. 세부 정책은 [AI-BUDGET.md](../AI-BUDGET.md)를 따릅니다.

## 학생에게 도움이 된다는 근거는 있나요?

실제 학생 결과는 아직 없습니다. 3명 예비테스트에서 사용 흐름의 막힘과 같은 사전·사후 명확성 질문, 다음 행동과 이유 설명을 확인할 준비를 하고 있습니다. 이후 정식 12명 파일럿과 동의자 대상 7일 확인을 계획합니다. 작은 표본의 결과를 전체 학생에게 일반화하지 않습니다.

## 팀원은 어떻게 나눠 작업했나요?

현재 기획·프론트·백엔드·디자인·발표·사용자 검증 담당은 모두 미정(제안안)입니다. 실제 배정 뒤 `TEAM-ROLES.csv`에 담당·검증·검토·발표 근거를 기입해 답합니다. AI 에이전트 분업을 학생 팀원의 직접 기여로 제시하지 않습니다.
