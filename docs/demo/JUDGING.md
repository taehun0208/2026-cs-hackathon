## 기술 증거를 설명하는 방식

- 테스트 수는 최종 통합된 커밋과 검사 결과를 확인한 뒤 말합니다. 기존 PR의 검사 수를 새 코드의 검사 수처럼 재사용하지 않습니다.
- 브라우저 보고와 서버 저장 확인을 구분합니다. AI가 코드를 실행하거나 학생의 적성을 검증했다고 말하지 않습니다.
- 도구 호출은 실제 활동 기록을 가리킵니다. 모델의 내부 추론이나 가짜 에이전트 팀 활동으로 설명하지 않습니다.
- AI 일 $1·월 $10 앱 추정 예약예산은 구현했고 실제 Neon에서 동시 예약·CAS·정산·정리를 검증했습니다. 최대 예약액 $0.162144 때문에 잔액이 남아도 기본 힌트가 나올 수 있습니다. 공급자 청구 상한이나 원가 최소 보장으로 표현하지 않습니다. 근거: [AI-BUDGET.md](../AI-BUDGET.md).

## 협업 증거를 준비하는 방식

현재 기획·프론트·백엔드·디자인·발표·사용자 검증 담당은 모두 **미정(제안안)**입니다.

[TEAM-ROLES.csv](TEAM-ROLES.csv)의 업무별 담당자와 산출물·검토 근거를 실제 팀원이 확인합니다. 한 사람이 여러 업무를 맡아도 괜찮습니다. 이름·학번·연락처를 공개 저장소에 넣을 필요는 없으며 팀이 공개에 동의한 표시만 사용합니다. AI 에이전트가 병렬로 작업한 사실은 제작 방법으로 설명할 수 있지만, 학생 팀원이 직접 담당한 역할이나 사용자 연구로 바꾸어 쓰지 않습니다.
