## 이번에 바로 고친 안내

진행 중 기록 카드가 누적 실행 횟수만 보고 ‘회고를 남기면 완료’라고 안내했습니다. 시작 코드를 그대로 실행했거나, 참고 풀이만 실행했거나, 마지막 실행 뒤 코드를 다시 수정한 경우에도 이 안내가 나왔습니다. 실제 회고 버튼은 현재 코드의 직접 수정·실행 근거가 있어야 활성화되므로 다음 행동이 서로 어긋났습니다.

카드도 실제 회고 가능 조건 `canRecordAttempt`를 사용하도록 수정했습니다. 시작 코드·수정 후 미실행·참고 풀이 실행은 수정/실행 안내, 현재 직접 수정한 코드의 실행은 회고 안내가 나옵니다. 실행 실패가 있어도 직접 수정·실행한 시도는 회고할 수 있습니다. 실제 컴포넌트에서 기록 화면과 체험 화면을 오가며 안내와 버튼 상태가 일치하는 회귀 검사를 추가했습니다.

이 검토는 코드와 기획의 제품 검토입니다. 학생 사용성 실험이나 보안 감사 결과를 대신하지 않습니다. 보안 점검은 별도 문서를 기준으로 확인합니다.
