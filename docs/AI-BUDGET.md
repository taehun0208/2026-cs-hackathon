# AI 운영 예산

이슈 #2 P1-6. 기존 브라우저·직무·전체 호출 횟수 제한에 **USD 기준 앱 예산**을 추가합니다. 계정 전체의 공급자 결제 한도를 설정하는 기능은 아닙니다.

## 기본 정책

- 요청 시작 시각의 UTC 하루 $1, 달력 한 달 $10. `AI_DAILY_BUDGET_USD`, `AI_MONTHLY_BUDGET_USD`로 변경하며 `0`은 AI를 중단합니다. 음수·빈 값·지수 표기·NaN 등 잘못된 값은 기본 힌트로 전환합니다. 값이 없는 기존 배포에는 위 기본값을 적용합니다.
- 현재 검수 가격은 `gpt-4.1-mini`, `gpt-4.1-mini-2025-04-14`의 standard tier입니다. 알 수 없는 모델·원장 연결 실패·예약 실패에는 공급자 요청을 보내지 않습니다. 현재 AI 동의·콘텐츠 근거·횟수 제한·전체 15초 기한을 유지합니다.
- 운영 예산을 예약하지 못하면 기본 힌트를 사용합니다. 체험·실행·학습 기록 저장은 계속 이용할 수 있습니다. 정산 확인 실패도 기본 힌트로 전환하며 기존 예약을 유지합니다.
- 80% 이상 예약·사용과 한도에 따른 거절은 익명 `ai_budget` 서버 경고 로그를 남기고 운영자 집계 명령에서도 확인합니다. 로그에는 이유·일/월·익명 합계/한도만 허용하며 원문·소유자·요청 ID·키는 넣지 않습니다. 이메일·메신저·외부 알림을 자동 발송하지 않습니다.

## 가격 근거와 한계

2026-11-23 [공식 GPT-4.1 mini 가격](https://developers.openai.com/api/docs/models/gpt-4.1-mini)을 확인했습니다. 입력은 100만 토큰당 $0.40, 출력은 $1.60입니다. 캐시 입력의 $0.10 할인은 적용하지 않아 할인으로 비용을 과소 계산하지 않습니다. 요청에 `service_tier: default`를 지정해 standard 가격 정책을 사용합니다. 단가는 코드의 검수 버전에 고정하며 가격·모델 변경 시 다시 검수해야 합니다.

**공식 [Deprecations](https://developers.openai.com/api/docs/deprecations)는 GPT-4.1 mini 스냅샷의 종료일을 2027-01-14로 안내합니다(2026-11-23 확인).** 현재 사용 가능 기간이지만 종료 전 모델 전환과 품질·단가 재검수가 필요합니다. 이번 변경은 모델을 자동 교체하지 않습니다. 실제 서비스 제공·종료 일정과 지원 여부를 운영자가 확인하고, 모델을 변경하려면 힌트 선택 평가와 가격 정책을 함께 갱신해야 합니다. 목록에 없는 모델은 비용을 추측해 호출하지 않습니다.

[Chat Completions 문서](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)의 `max_completion_tokens`, `usage`, `service_tier`를 기준으로 구성했습니다. 모델이 반환한 `prompt_tokens`와 `completion_tokens`가 유효할 때만 사용량이 확인됐다고 셉니다. usage가 빠진 호출은 운영 로그의 outcome에도 `usage_unconfirmed`로 구분합니다. 토큰 수·단가 기반 앱 추정치이며 공급자 청구서와 일치한다고 보장하지 않습니다. 가격 변경, 세금·환율, 다른 앱·평가 스크립트의 호출, 수신하지 못한 응답은 실제 계정 비용과 차이가 날 수 있습니다. 공급자 계정의 사용량·결제 정책도 별도로 확인합니다.

## 예약과 정산

- 정수 나노달러(1 USD = 1,000,000,000 단위)로 계산해 토큰당 소수 단가를 보관합니다.
- AI 작업 하나의 최대 3라운드를 호출 **전에 한 번에 예약**합니다. 라운드당 공급자 JSON 본문은 UTF-8 131,072바이트를 넘기지 않고 출력 상한은 500토큰입니다. 직렬화된 코드·질문·프롬프트·도구·도구 결과·이전 도구 호출·마지막 지시를 모두 포함한 바이트 수를 매 라운드 검사합니다.
- UTF-8 바이트 수를 입력 토큰 수의 보수적 근사 상한으로 잡고 메시지·도구 프레이밍에 2,048토큰 여유를 추가합니다. 이 정책의 최대 작업 예약은 **$0.162144**입니다. 공급자 내부 토큰화·프레이밍의 수학적 청구 상한을 증명한 것은 아니므로 실제 usage가 예상을 넘으면 그 실제 추정 비용을 원장에 반영하고 이후 요청을 제한합니다.
- 월 원장 하나에 날짜별 예약을 함께 두고 revision 조건부 UPDATE(CAS) 한 번으로 일·월 한도를 확인합니다. 서버 인스턴스가 달라도 같은 revision을 둘 다 덮어쓰지 못합니다. 충돌은 최신 합계로 최대 12번 재시도하며 계속 실패하면 호출하지 않습니다. 일 예약만 성공하는 부분 상태가 없습니다.
- 모든 전송 응답의 usage를 확인한 경우 합계 비용으로 정산하고 남은 예약을 돌려놓습니다. 일부 실패·타임아웃·usage 누락은 전체 예약을 유지합니다. 시간만 지났다는 이유로 예약을 자동 해제하지 않습니다. 요청이 공급자에서 처리됐을 가능성이 있기 때문입니다.
- 정산은 요청 ID별 한 번만 반영합니다. 잘못된 예산 원장은 자동 초기화하지 않고 AI를 중단합니다. 원장 요청 ID는 앱 내부 UUID이며 소유자 쿠키·학번·이름·코드·질문·회고·키·공급자 응답 원문을 저장하지 않습니다.
- 기록 삭제는 당일 횟수나 익명 예산을 초기화하지 않습니다. 원장은 현재 월과 이전 두 달을 유지하고 이전 월은 기존 일일 정리 작업에서 삭제합니다. 30일 학생 기록 보관과 별도의 익명 운영 집계입니다.

## 준비와 운영

배포 전에 추가 마이그레이션 `003_ai_budget.sql`을 실행해야 합니다. 기존 체험 상태는 변경하지 않습니다. 새 비밀키나 외부 서비스는 필요하지 않습니다. 마이그레이션이 없거나 DB에 연결하지 못하면 AI는 기본 힌트로 전환합니다.

```sh
npm run db:migrate
node scripts/report-ai-budget.mjs
node scripts/report-ai-budget.mjs --sqlite /absolute/path/to/local-qa.sqlite
```

서버 경고는 예약을 포함한 합계 기준이라 정산 후 사용액이 내려갈 수 있고, 같은 임계값에서 다시 발생할 수 있습니다. 설정·저장소·정산 확인 실패도 원문 없는 이유 코드로 기록합니다.

출력에는 UTC 일·월 한도, 정산 합계와 남겨둔 예약 합계, 80% 경고, 다음 최대 요청 예약 차단 여부가 나옵니다. 원본 요청 ID·소유자·연결 문자열은 출력하지 않습니다. CLI가 없다는 이유로 서버가 예산 확인을 생략하지 않습니다. 환경 설정이 잘못되면 CLI도 disabled 상태와 조치 안내를 반환합니다.

일 $1/월 $10은 파일럿용 초기 설정이며 사용자가 승인한 별도 결제나 충전이 아닙니다. 예산 변경은 운영자의 선택입니다. 낮은 잔액에서는 실제로 작은 요청이더라도 최대 작업 예약을 확보하지 못해 기본 힌트로 전환할 수 있습니다. 알 수 없는 비용의 예약이 누적되면 운영자가 공급자 기록과 대조한 뒤 정책을 결정해야 하며 임의 환불 버튼은 제공하지 않습니다.

`eval-coach.mjs`는 기존과 같이 학습자 DB를 읽지 않으며, 전용 메모리 원장으로 **프로세스 내** 예산을 적용합니다. 운영 원장과 공유하지 않으므로 실제 평가 호출은 운영 사이트 예산 합계에 포함되지 않습니다. `--live`는 별도 명시적 실행이며 이번 검증에서는 실행하지 않았습니다.

## 검증

모의 공급자·SQLite 기반으로 일/월 동시 예약, 중복 정산, UTC 일·월 경계, 원장 정리, 누락·실패·타임아웃·늦은 예약, 정산 DB 오류, 알 수 없는 모델·환경 설정, UTF-8/이스케이프·긴 도구 메시지의 본문 제한을 확인했습니다. 기존 AI 도구·품질·기한 테스트는 비용 저장 모의 객체만 추가해 동일한 기능을 계속 검사합니다. 통합 단위 199개·빌드·타입 검사 통과, 독립 예산 코드 검수에서 차단 결함은 발견하지 못했습니다.

2026-11-23 연결된 Neon에 추가 스키마 003을 적용하고 아래 검사를 실행해 동시 예약 8건 중 한도 내 5건만 허용, 각각 정산 후 합계 보존을 확인했습니다. 합성 `2999-01` 행은 검사 후 제거했습니다. 현재 월 예산이나 학생 상태는 시험 데이터로 덮어쓰지 않았습니다. 이 검사는 실제 모델 호출을 하지 않습니다.

실제 PostgreSQL의 CAS 동시성 검사는 마이그레이션 후 운영자가 명시적으로 실행할 수 있습니다. 이 검사는 현재 월·학습자 기록 대신 `2999-01` 합성 원장만 만들고 검사 후 제거합니다. 기존 해당 기간 행이 있으면 덮어쓰지 않고 중단합니다.

```sh
LAB_BUDGET_NEON_TEST=1 node --env-file=.env.local tests/ai-budget-neon-smoke.mjs
```
