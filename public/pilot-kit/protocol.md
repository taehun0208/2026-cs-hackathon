# 해보기 학생 파일럿 진행안

상태: 준비용 v1. 참여자를 모집하거나 실험을 진행한 결과가 아닙니다. PR의 main 병합·배포 확인 후 사용합니다.

## 목적과 범위

학생이 설명 없이 첫 수정·실행·회고·비교·다음 행동까지 갈 수 있는지, 두 직무를 경험한 뒤 다음 학습 방향이 명확해지는지 관찰합니다. 적성·실력·취업 가능성을 평가하지 않습니다. 현재 여섯 직무의 JavaScript 직접 수정 체험을 대상으로 하며 선택 게임은 별도 관찰입니다. PRD의 세 작업 방식 전체를 시험하는 설계가 아닙니다.

총 12명을 계획합니다. JavaScript 경험 없음/기초/프로젝트 경험자를 가급적 네 명씩 포함하되 실제 모집 내역과 편차를 기록합니다. 학년·학번·실명을 분석 파일에 적지 않습니다. 각 학생이 두 직무를 경험합니다. 여섯 직무는 각각 네 번, 첫째·둘째 순서로 각각 두 번 배치됩니다. 모든 직무 쌍이나 학과 전체를 대표하는 무작위 표본은 아닙니다.

## 준비물과 시작 조건

- 배포 버전·브라우저·날짜를 진행자가 기록합니다. 기존 기록이 없는 별도 브라우저 프로필을 권장하되 기존 사용자 기록을 임의로 지우지 않습니다.
- 진행자 QA 번호로 시작→실행→회고 저장→비교→참여 철회·삭제를 먼저 검사합니다. QA 분석은 실제 파일럿에서 제외합니다.
- 명확성 사전 질문을 받기 전 체험 목표나 정답을 설명하지 않습니다. 관찰 및 후속 연락에 대한 참여 의사를 따로 확인합니다. 언제든 중단할 수 있고 참여 여부가 성적에 영향을 주지 않는다고 설명합니다.
- 앱의 ‘체험 개선 참여’는 별도 선택입니다. 원한다면 동의 전 참여 번호를 고릅니다. 수집을 원하지 않아도 체험과 관찰 참여는 가능합니다. 분석 비동의자는 이벤트 분모에 없다는 점을 기록합니다.
- 세 CSV는 빈 양식입니다. 연락처·동의 원본은 팀의 접근 제한 공간에 별도로 보관하며 완료된 CSV, 연락처, 화면 녹화나 학생 코드를 공개 저장소에 올리지 않습니다. 연구용 작성 파일은 종료·7일 확인 이후 30일 안에 폐기합니다. 후속 연락에 동의하지 않은 학생에게 연락하지 않습니다.

## 모집 문구 초안 — 진행자가 직접 전달

컴퓨터학부 학생을 위한 직무 체험 서비스를 시험 사용해볼 학생을 찾습니다. 약 35~45분 동안 두 직무를 짧게 경험하고 사용하면서 느낀 점을 들려주세요. 코딩 실력이나 적성을 평가하는 자리가 아니며, 막히거나 끝내지 못한 경험도 도움이 됩니다. 언제든 쉬거나 그만둘 수 있습니다. 앱 활동 기록 수집은 선택이고, 원하시는 분께만 7일 뒤 후속 질문을 드립니다. 참여 의사와 가능한 시간은 진행자에게 알려주세요.

## 진행 — 안내용 예상 35~45분, 실측 아님

1. 0~5분: 참여 안내·의사 확인, 경험 수준, AI 도구 사용 경험, 탐색 목적, 사전 명확성 질문. 참여번호만 기록합니다.
2. 5~15분: 배정된 첫 직무. ‘이 화면에서 이 일을 해보세요’만 말하고 정답·버튼 위치를 먼저 가리키지 않습니다.
3. 15~25분: 둘째 직무. 모든 테스트를 통과하지 않아도 직접 수정·실행했으면 회고를 남길 수 있습니다. 약 10분이 지나도 어려우면 중단·분할 참여를 제안하고 중단 지점을 기록합니다.
4. 25~35분: 비교하기, 같은 사후 명확성 질문, 다음 행동과 이유 설명. 미완료자도 사후 질문을 받습니다.
5. 35~45분: 원하면 게임 하나, 사용성 인터뷰와 후속 연락 의사 확인. 게임은 두 코드 직무 종료 지표에 섞지 않습니다.

3분 이상 막히면 ‘지금 화면에서 다음으로 무엇을 할 수 있을까요?’라고 묻고 개입 수준을 기록합니다(0 없음 / 1 중립 질문 / 2 위치 안내 / 3 풀이 안내). 정답을 알려준 경우 자력 완료로 표현하지 않습니다. 불편·중단 요청·시간 부담이 있으면 즉시 멈춥니다.

## 사전·사후 동일 질문

“다음에 무엇을 배울지 얼마나 분명한가요?”

1 전혀 분명하지 않다 / 2 별로 분명하지 않다 / 3 보통이다 / 4 어느 정도 분명하다 / 5 매우 분명하다.

사전 질문은 첫 체험 이전, 사후 질문은 비교 이후 또는 중단 직후에 묻습니다. 미응답은 빈칸으로 남기며 0·1점으로 바꾸거나 사후 응답으로 사전을 채우지 않습니다.

추가 맥락: JavaScript 경험(없음/기초/프로젝트), AI 코딩 도구 사용(없음/가끔/자주), 이번 탐색 목적(다음 학습/팀 역할/직무 이해/미응답). 이름이나 사생활 설명을 요구하지 않습니다.

## 관찰·인터뷰 질문

- 첫 화면에서 무엇부터 할 것 같았나요? 실제 첫 행동과 막힌 위치를 구분해 기록합니다.
- 이 직무에서 직접 바꿔본 것은 무엇인가요? 개념을 자기 말로 설명했는지 여부만 표시하고 코드·회고 원문을 복사하지 않습니다.
- 힌트나 풀이를 본 뒤 무엇을 바꿔야 할지 알 수 있었나요?
- 두 직무 중 더 해보고 싶은 쪽과 이유는 무엇인가요? 적성 순위로 해석하지 않습니다.
- 다음에 할 작은 일 하나와 그 이유를 설명해줄 수 있나요? 앱이 제안했다는 사실과 학생이 실제로 선택·설명했다는 사실을 구분합니다.
- 끝내지 못했다면 어디에서 멈췄나요? 버튼·문법·설명·시간·오류 등으로 분류하고 자유 원문 복사는 피합니다.

## 7일 뒤 — 후속 연락 동의자 전체, 미완료자 포함

진행자가 실시일+7일을 확인 예정일에 적습니다. 연락은 자동 발송하지 않습니다. 참여번호로 다음을 확인합니다.

- 선택한 활동을 실제로 시작했나요? 예 / 아니오 / 기억나지 않음.
- 시작했다면 학습·추가 체험·작은 프로젝트·탐색 중 어떤 일을 언제 했나요? 자기 응답으로 표시합니다. 학생이 자발적으로 보여준 근거가 있는 경우에만 확인 여부를 별도로 표시하고 원본을 복사하지 않습니다.
- 시작하지 못했다면 시간·난이도·방향 미정·다른 우선순위·기타 중 이유를 고릅니다.
- 다음 계획이 바뀌었나요? 응답 없음은 ‘시작 안 함’으로 바꾸지 않습니다.

## 지표와 분모

| 지표 | 계산과 주의 | 제안 목표 |
| --- | --- | --- |
| 첫 체험 종료 | 관찰상 첫 코드를 수정·실행하고 회고 저장까지 한 학생 / 첫 체험을 시작한 학생. 이벤트 집계는 동의 브라우저의 첫 관측 ‘새 체험’만 대상으로 따로 보고 | 60% |
| 두 직무+다음 행동 | 서로 다른 두 코드 직무의 회고를 저장하고 활동을 선택한 학생 / 첫 체험 시작 학생 | 40% |
| 명확성 변화 | 두 직무 종료자 중 유효한 사전·사후 쌍에서 1점 이상 오른 학생 / 유효 쌍 수. 전체 응답자 쌍의 탐색 결과는 별도 표 | 70% |
| 선택의 구체성 | 두 직무 종료자 중 다음 행동과 이유를 직접 설명한 학생 / 질문에 답한 두 직무 종료자. 질문 미응답도 따로 보고 | 70% |
| 7일 후 시작 | 시작했다고 자기 응답한 학생 / 유효한 후속 응답자. 응답률(응답자/연락 동의자)과 함께 보고 | 보조 관찰 |

목표값은 기존 PRD의 제안값이며 실측 성과가 아닙니다. n=0이면 비율을 계산하지 않습니다. 게임·코드, 새 시작·이어하기, 콘텐츠 버전, 도움 사용·진행자 개입을 구분합니다. 누락·오프라인·측정 거부·쿠키 변경을 이탈로 단정하지 않습니다. 다음 활동 선택은 회고 안에서 비교 전에 일어날 수 있으므로 ‘비교→선택’ 순차 전환이라고 계산하지 않습니다.

## 분석 도구

운영자는 서버 접근 권한이 있는 로컬 환경에서만 집계합니다.

```sh
node scripts/report-analytics.mjs --since YYYY-MM-DD --until YYYY-MM-DD --cohort pilot > /private/path/pilot-report.json
```

날짜는 UTC이며 until은 제외 경계입니다. QA는 기본 제외합니다. 출력은 집계이며 쿠키에 해당하는 원본 소유자 키, 토큰, 세션·여정 ID를 내보내지 않습니다. 같은 참여번호에 여러 익명 브라우저가 있으면 품질 경고 수로 확인하고 관찰 양식과 대조합니다. 실제 학생 명확성·후속 응답은 자동 수집하지 않으며 별도 양식으로 결합해 읽습니다.

## 종료 후 준비 완료 확인

- 12명 모집·참여·실시·중단·후속 동의 인원을 실제 값으로 채웠는가?
- 동의별 이벤트 분모와 관찰 분모, 누락 응답을 따로 표시했는가?
- 심각한 시작·저장·삭제 장애는 파일럿 확대 전에 수정했는가?
- 작은 표본 결과를 전체 학생의 적성이나 취업 성과로 일반화하지 않았는가?
